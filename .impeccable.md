# Design Context - TechInsiderBytes Dashboard V2

## Project Overview
- Type: Control Room Dashboard (ops monitoring)
- Stack: Next.js 16 + React 19 + Tailwind CSS 4
- Theme: Linear Dark Mode (NOT Vercel Light)

## Users & Purpose
- Who: AI operators monitoring MIMULE / TechInsiderBytes stack
- Context: Night monitoring, quick status checks, pipeline control
- Need: Dense information, fast updates, instant actions

## Brand Personality
- Voice: Technical, operational, crisp
- Three words: Dense, dark, functional

## Aesthetic Direction

### Theme (Dark - NOT Light)
- Background: #0d0d0f (NOT #ffffff)
- Foreground: #f4f4f5 (NOT #171717)
- Card background: #18181b
- Border: #27272a

### Accent Colors
- Primary: #5e6ad2 (purple accent - NOT Vercel workflow colors)
- Success: #22c55e (green)
- Warning: #eab308 (yellow)
- Error: #ef4444 (red)

### Typography
- Font: Inter + JetBrains Mono (NOT Geist)
- No negative letter-spacing needed
- Standard weights: 400, 500, 600

### Component Styling
- Use standard CSS borders (NOT shadow-as-border technique)
- Border radius: 6px standard
- Dark mode by default

## Design Principles (Override Vercel Defaults)
1. Always dark theme - never default to light
2. Use purple #5e6ad2 as primary accent
3. Standard borders, not shadow-borders
4. Green pulsing for "operational" status
5. No Vercel-style negative tracking

## What NOT to Do (Anti-Patterns for THIS Project)
- Don't switch to light theme
- Don't use Vercel shadow-borders
- Don't add negative letter-spacing
- Don't use Vercel workflow colors (Ship Red, Preview Pink, Develop Blue)
- Don't center-align everything

## Key Files
- Style: /opt/DESIGN.md
- Dashboard: /opt/dashboard-v2/
- Globals: /opt/dashboard-v2/src/app/globals.css

## IMPORTANT: Run Rules
Before ANY design work:
1. Read /opt/dashboard-v2/src/app/globals.css for current CSS variables
2. Check /opt/DESIGN.md for exact colors
3. NEVER apply Vercel-style design blindly - this is a DARK dashboard
4. Test changes at http://localhost:3000 (dev) before production
